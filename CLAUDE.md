# CLAUDE.md

The agent documentation for this repository lives in
**[`AGENTS.md`](AGENTS.md)** — read it first. This file exists only so
Claude Code finds it in this directory.

Skills are defined once, under `.agents/skills/<name>/SKILL.md`. The copies
under `.claude/skills/` are pointers to those files, kept only so Claude
Code lists them; edit the canonical copy, not the pointer.
